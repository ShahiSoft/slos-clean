# Compliance Score Calculation Reference

_Reference for: IMPLEMENTATION-PLAN.md → Phase 0.1_

---

## Purpose

The Compliance Readiness Score replaces the current single-metric "Compliance Health Score" (based solely on consent acceptance rate) with a multi-dimensional model that reflects actual configuration completeness and operational readiness.

**Key Principle:** The score measures *how well the site is configured for compliance*, not *legal compliance itself*. Always display a disclaimer.

---

## Score Dimensions

| Dimension | Weight | Description |
|-----------|--------|-------------|
| `COOKIES` | 25% | Cookie scanning coverage and categorization completeness |
| `LEGAL_DOCS` | 25% | Presence and publication status of required legal pages |
| `GEO_RULES` | 15% | Geo targeting configuration vs detected traffic regions |
| `CONSENT_METADATA` | 15% | Richness of consent records (geo, language, versioning) |
| `SCANNING_FRESHNESS` | 10% | Recency of last cookie scan |
| `BANNER_CONFIG` | 10% | Banner configuration completeness (all templates, texts, actions) |

**Total:** 100%

---

## Dimension Scoring Logic

### 1. COOKIES (25%)

```
cookies_score = (categorized_cookies / total_cookies) * 100

Adjustments:
- If total_cookies == 0 and scan never run: 0
- If total_cookies == 0 and scan completed: 100 (no cookies found)
- Penalty: -10 per cookie marked "unknown" provider
```

**Data Sources:**
- `get_option('slos_cookie_inventory')` → array of cookies with `category`, `status` (per `Cookie_Scanner_Service`)
- `get_option('slos_cookie_scan_time')` → last scan timestamp

### 2. LEGAL_DOCS (25%)

```
required_docs = ['privacy_policy', 'cookie_policy', 'accessibility_statement']
published_docs = count of required docs with status == 'publish'

legal_docs_score = (published_docs / count(required_docs)) * 100

Optional boost:
- +5 if cookie_policy is auto-generated from scanner data
- +5 if accessibility_statement was generated by the plugin
```

**Data Sources:**
- WP option storing page IDs for each doc type (e.g., `slos_legal_pages`)
- `get_post_status($page_id)` for each

### 3. GEO_RULES (15%)

```
configured_regions = regions with active rules
detected_traffic_regions = regions seen in consent records (last 30 days)

coverage = count(configured_regions ∩ detected_traffic_regions) / count(detected_traffic_regions)
geo_rules_score = coverage * 100

Fallback:
- If no traffic data yet: check if at least 1 rule is configured → 50; else 0
```

**Data Sources:**
- Geo rules table/option
- `Consent_Repository::get_distinct_regions(since: -30 days)`

### 4. CONSENT_METADATA (15%)

```
recent_consents = consents from last 30 days
complete_consents = consents with: country_code NOT NULL, language NOT NULL, banner_version NOT NULL

consent_metadata_score = (complete_consents / recent_consents) * 100

Fallback:
- If no recent consents: 100 (nothing to penalize)
```

**Data Sources:**
- `Consent_Repository::get_recent(limit: 1000, since: -30 days)`

### 5. SCANNING_FRESHNESS (10%)

```
days_since_scan = (now - last_scan_time) / 86400

If days_since_scan <= 7: scanning_freshness_score = 100
Else if days_since_scan <= 30: scanning_freshness_score = 70
Else if days_since_scan <= 90: scanning_freshness_score = 40
Else: scanning_freshness_score = 10

If never scanned: 0
```

**Data Sources:**
- `get_option('slos_cookie_scan_time')`

### 6. BANNER_CONFIG (10%)

```
required_fields = [
  'banner_enabled',
  'primary_button_text',
  'reject_button_enabled',
  'preferences_link_enabled',
  'privacy_policy_link',
]

configured_fields = count of required_fields that are set and non-empty

banner_config_score = (configured_fields / count(required_fields)) * 100
```

**Data Sources:**
- Settings from `get_option('shahi_legalflowsuite_settings')` (per `Settings::OPTION_NAME`)
- Access via `Settings::get_settings()` class method

## Aggregate Score Calculation

```php
$weights = [
    'COOKIES'            => 0.25,
    'LEGAL_DOCS'         => 0.25,
    'GEO_RULES'          => 0.15,
    'CONSENT_METADATA'   => 0.15,
    'SCANNING_FRESHNESS' => 0.10,
    'BANNER_CONFIG'      => 0.10,
];

$aggregate = 0;
foreach ($dimensions as $dim => $score) {
    $aggregate += $score * $weights[$dim];
}

$readiness_score = round($aggregate);
```

## Service Interface

```php
namespace ShahiLegalFlowSuite\Services;

class Compliance_Score_Calculator {

    /**
     * Calculate all dimension scores and aggregate.
     *
     * @return array {
     *     @type int   $score       Aggregate readiness score (0-100)
     *     @type string $grade      Letter grade (A-F)
     *     @type string $label      Human-readable label
     *     @type array  $dimensions Per-dimension scores and metadata
     * }
     */
    public function calculate(): array;

    /**
     * Get score for a single dimension.
     *
     * @param string $dimension One of the dimension constants.
     * @return array { @type int $score, @type array $details }
     */
    public function calculate_dimension( string $dimension ): array;
}
```

## Dashboard Display Recommendations

### Primary Visualization

- **Option A:** Segmented circular gauge with arcs per dimension.
- **Option B:** Spider/radar chart with 6 axes.
- **Option C:** Stacked horizontal bar with color-coded segments.

### Per-Dimension Cards

Below the primary gauge, show 6 small cards:

```
┌───────────────────────────────────────────────────────────────────┐
│  🍪 Cookies: 85%       📄 Legal Docs: 100%    🌍 Geo Rules: 60%  │
│  📋 Consent Data: 90%  🔄 Scan Fresh: 100%    ⚙️ Banner: 80%     │
└───────────────────────────────────────────────────────────────────┘
```

Each card is clickable → navigates to the relevant tab or shows a tooltip with details.

### Disclaimer Microcopy

> **Note:** This Readiness Score reflects configuration completeness and is not a guarantee of legal compliance. Please consult with a legal professional for compliance advice.

## Testing Scenarios

| Scenario | Expected Score |
|----------|----------------|
| Fresh install, nothing configured | 0–10 |
| Scan run, all cookies categorized, no legal docs | ~50 |
| Full config, all docs published, scan <7 days old | 95–100 |
| Outdated scan (90+ days), missing cookie policy | ~60 |
| Perfect config but no consents yet | 95+ (consent metadata defaults to 100 if no data) |

## Migration Notes

- The existing `get_dashboard_stats()` method in `ComplianceMainPage` should be refactored to call `Compliance_Score_Calculator::calculate()`.
- The old `compliance_score` (acceptance-based) can be deprecated but kept in the return array as `legacy_acceptance_rate` for backward compatibility.
- Frontend JS that renders the gauge will need to handle the new `dimensions` array.
