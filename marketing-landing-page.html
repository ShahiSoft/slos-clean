Our revolutionary accessibility system goes beyond detection—it automatically fixes issues. From focus indicators and touch targets to ARIA landmarks and language attributes, we've got you covered.

New in 3.4.0: Added 5 new fixer classes (LanguageChangeFixer, StatusMessageFixer, AnimationPauseFixer, TimingControlFixer, ErrorIdentificationFixer) and enhanced 7 existing fixers.

  • Automatic focus indicator injection
  • Touch target resizing (44x44px minimum)
  • Keyboard trap escape handlers
  • Animation pause/play controls
  • 12-language detection system
  • ARIA live regions for status messages

🌍 Geo-Aware Consent Management

Automatically detects visitor location and serves the appropriate consent template. EU visitors get GDPR, California gets CCPA, Brazil gets LGPD—all automatically.

Phase 4.1 Complete: Server-side geo detection with Geo_Service, frontend fallback via REST API, and multi-layer template matching.

  • IP-based geolocation
  • 4 regional templates (Simple, GDPR, CCPA, Advanced)
  • Geo_Rule_Matcher integration
  • Consent record geo tracking
  • Automatic compliance mapping
// Geo Detection Flow 1. Server-side: Geo_Service detects region 2. Rule Matcher: Matches geo_rule templates 3. Frontend Fallback: /wp-json/slos/v1/geo/region 4. Region Mapping: EU→GDPR, US-CA→CCPA 5. Consent Record: Stores geo_rule_id Result: EU visitor → GDPR banner ✅ Result: CA visitor → CCPA banner ✅ Result: BR visitor → LGPD banner ✅

📊 A/B Testing & Analytics

Built-in A/B testing infrastructure with variant assignment, persistent storage, and comprehensive analytics events for every user interaction.

Phase 4.2 & 4.3: Variant tracking in consent metadata, duration measurement, and CustomEvent API for Google Analytics, Segment, and Mixpanel.

  • 50/50 variant assignment
  • Persistent localStorage tracking
  • 5 analytics events (shown, accepted, rejected, customized, updated)
  • Time-to-decision measurement
  • Cohort analysis ready
// Analytics Events document.addEventListener('slos-consent-shown', (e) => { gtag('event', 'consent_shown', { variant: e.detail.variant, // "A" or "B" template: e.detail.template, // "gdpr" region: e.detail.region, // "EU" policyVersion: e.detail.version // "2.0" }); }); document.addEventListener('slos-consent-accepted', (e) => { gtag('event', 'consent_accepted', { categories: e.detail.categories, // [...] duration: e.detail.duration, // ms variant: e.detail.variant // "A" }); });
