## Accessibility Compliance

### WCAG 2.1 AA Compliance

#### Accessibility Principles
- **Perceivable:** Information must be presentable
- **Operable:** Interface elements must be operable
- **Understandable:** Information must be understandable
- **Robust:** Content must be robust

#### WCAG Success Criteria
- **1.1 Text Alternatives:** Non-text content alternatives
- **1.3 Adaptable:** Content can be presented differently
- **1.4 Distinguishable:** Content distinguishable from background
- **2.1 Keyboard Accessible:** Keyboard navigation
- **2.4 Navigable:** Easy navigation and location
- **3.1 Readable:** Readable and understandable text
- **3.3 Input Assistance:** Help users avoid/correct mistakes
- **4.1 Compatible:** Compatible with assistive technologies
