- **Fraud Prevention:** Automated fraud detection

#### 3. Request Details

#### 4. Review and Submit
- **Summary Review:** Review all entered information

### Request Types Interface

#### Access Request
- **Data Categories:** Select types of data to access
- **Time Period:** Specify time period for data
- **Format Preference:** Choose preferred export format
- **Delivery Method:** Email or secure download

#### Rectification Request
- **Data to Correct:** Specify incorrect data
- **Correct Information:** Provide correct information
- **Supporting Evidence:** Upload evidence if needed
- **Urgency Level:** Indicate urgency if applicable

#### Erasure Request
- **Erasure Reason:** Select legal basis for erasure
- **Data Scope:** Specify data to be erased
- **Retention Exceptions:** Acknowledge any exceptions
- **Impact Assessment:** Understand consequences

#### Restriction Request
- **Restriction Reason:** Explain restriction request
- **Processing Types:** Specify processing to restrict
- **Duration:** Request temporary or permanent restriction
- **Communication:** Control communications during restriction

#### Portability Request
- **Data Format:** Choose machine-readable format
- **Data Scope:** Select data for portability
- **Recipient:** Specify where to send data
- **Direct Transfer:** Request direct transfer to another controller

#### Objection Request
- **Objection Basis:** Select legal basis for objection
- **Processing Types:** Specify processing to object to
- **Scope:** Individual or general objection
- **Marketing Preferences:** Control marketing communications
