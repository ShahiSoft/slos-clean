# DSR Portal Overview

## What is DSR Portal?

The Data Subject Rights (DSR) Portal provides a secure, user-friendly interface for individuals to exercise their data privacy rights. It handles GDPR, CCPA, and LGPD data subject requests with automated workflows, secure data processing, and comprehensive audit trails.

## Key Features

### Request Types

#### 1. Access Request (Right to Access)
- **Purpose:** Individuals can request copies of their personal data
- **GDPR Article 15:** Right to obtain confirmation and copy of personal data
- **CCPA Section 1798.110:** Right to know about personal information collected
- **Response Time:** 30 days (GDPR), 45 days (CCPA)
- **Format:** Portable, structured, commonly used format

#### 2. Rectification Request (Right to Rectification)
- **Purpose:** Correct inaccurate or incomplete personal data
- **GDPR Article 16:** Right to rectification of inaccurate data
- **CCPA Section 1798.110:** Right to correct inaccurate information
- **Process:** Verify identity, locate data, make corrections
- **Notification:** Inform recipients of rectification

#### 3. Erasure Request (Right to Erasure/"Right to be Forgotten")
- **Purpose:** Delete personal data in certain circumstances
- **GDPR Article 17:** Right to erasure in specific cases
- **CCPA Section 1798.105:** Right to delete personal information
- **Conditions:** No longer necessary, consent withdrawn, unlawful processing
- **Exceptions:** Legal obligations, public interest, legal claims

#### 4. Restriction Request (Right to Restriction)
- **Purpose:** Limit processing of personal data
- **GDPR Article 18:** Right to restriction in specific cases
- **Process:** Mark data as restricted, inform recipients
- **Duration:** Until restriction conditions no longer apply
- **Limited Processing:** Storage only, no other processing

#### 5. Portability Request (Right to Data Portability)
- **Purpose:** Receive personal data in machine-readable format
- **GDPR Article 20:** Right to data portability
- **CCPA Section 1798.110:** Right to obtain personal information
- **Format:** Structured, commonly used, machine-readable
- **Scope:** Data provided by individual, processed automatically

#### 6. Objection Request (Right to Object)
- **Purpose:** Object to processing based on legitimate interests
- **GDPR Article 21:** Right to object to processing
- **Process:** Cease processing unless compelling grounds
- **Direct Marketing:** Absolute right to object to direct marketing
- **Automated Decisions:** Right to object to automated profiling
