## 💡 Common Questions

**Q: Is this plugin GDPR compliant?**
A: The plugin helps achieve compliance but compliance is a comprehensive requirement. See [System Requirements](./Getting%20Started/05-system-requirements.md).

**Q: How often should I scan for accessibility?**
A: At least weekly. See [Run Accessibility Scans](./How-tos/03-run-accessibility-scan.md).

**Q: Can I use this on multiple sites?**
A: Yes! See [Module Management](./Getting%20Started/04-module-management.md).

**Q: What about performance impact?**
A: Minimal. See [Performance Optimization](./Troubleshooting/02-performance-optimization.md).

**Q: How do I customize for my needs?**
A: Use hooks and filters. See [Hooks & Filters](./Advanced/02-hooks-filters.md).
