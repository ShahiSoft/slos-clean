# Onboarding Wizard

## Overview

The onboarding wizard guides you through initial setup when you first activate the plugin. It takes 5-10 minutes and sets up your core configuration.

## Wizard Steps

### Step 1: Welcome
- Introduction to Shahi LegalFlowSuite
- Overview of available modules
- Time estimate for setup

### Step 2: Company Profile
Fill in your organization details:
- **Company Name** - Legal business name
- **Website URL** - Your site URL (auto-filled)
- **Contact Email** - Primary contact email
- **Business Type** - Select from dropdowns
- **Address** - Full company address (for legal documents)
- **Phone Number** - Optional contact number
- **Industry** - Industry classification
- **Data Protection Officer** - DPO contact (optional)

*This information is used in generated legal documents and compliance records.*

### Step 3: Module Selection
Choose which modules to enable:
- **Consent Management** - Cookie consent and GDPR compliance
- **Accessibility Scanner** - WCAG 2.1 AA scanning and auto-fix
- **Legal Documents** - Generate Privacy Policy, Terms, etc.
- **DSR Portal** - Data Subject Rights requests

You can enable/disable modules anytime later in Settings.

### Step 4: Compliance Preferences
Set your compliance profile:
- **Applicable Regulations** - Select GDPR, CCPA, LGPD, etc.
- **Default Language** - Primary language for documents
- **Auto-fix Accessibility Issues** - Enable/disable auto-repair
- **Consent Collection Method** - Explicit opt-in or other
- **Data Retention** - How long to keep consent records

### Step 5: Review & Activate
- Review all settings
- Confirm module activation
- Complete wizard

## After Onboarding

The plugin is ready to use! Access modules via:
- **SLOS Dashboard** - Main overview
- **SLOS Settings** - Configuration
- Module-specific pages for each feature

## Skipping the Wizard

If you skip the wizard:
1. Default settings apply
2. All modules stay disabled initially
3. Enable modules in **SLOS** → **Settings** → **Modules**
4. You can re-run the wizard anytime via **SLOS** → **Help** → **Run Setup Wizard**

## Resetting Onboarding

To restart the wizard:
1. Go to **SLOS** → **Settings** → **Advanced**
2. Click **Reset Setup Wizard**
3. Wizard runs on next admin visit
