# Services Directory

This directory contains service classes for the Accessibility Scanner refactored architecture (Phase 4).

## Purpose
Service classes encapsulate business logic and provide reusable functionality:
- BackupService: Content backup and restore operations
- ConsolidationService: Result aggregation and merging
- StatisticsService: Metrics calculation and reporting
- ScannerService: Page scanning orchestration
- FixerService: Accessibility fix application

## Namespace
All services use the namespace: `ShahiLegalFlowSuite\Modules\AccessibilityScanner\Services`

## Implementation Status
Phase 4 implementation in progress. Services will be created incrementally following the Strangler Fig pattern.
