# Controllers Directory

This directory contains controller classes for AJAX request handling (Phase 4).

## Purpose
Controller classes handle HTTP requests and coordinate between services:
- ScannerAjaxController: Handles scan-related AJAX requests
- FixerAjaxController: Handles autofix-related AJAX requests

## Namespace
All controllers use the namespace: `ShahiLegalFlowSuite\Modules\AccessibilityScanner\Controllers`

## Implementation Status
Phase 4 implementation in progress. Controllers will be created after services are implemented.
